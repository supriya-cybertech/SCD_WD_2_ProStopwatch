# ⏱️ Professional Stopwatch Web App  
A modern, responsive stopwatch with **dark/light mode**, **lap tracking**, and **smooth animations**. Built for precision, usability, and style.  

## ✨ Features  

- 🌗 **Dark/Light Mode** – Switch themes instantly for any environment  
- 🏁 **Lap Tracking** – Record, view, and reset multiple laps with accuracy  
- 🎞️ **Smooth Animations** – Elegant transitions for start, stop, reset, and theme toggle  
- 📱 **Responsive Design** – Works seamlessly on desktop, tablet, and mobile  
- ⚡ **Lightweight & Fast** – Minimal dependencies, optimized performance  

## 🛠️ Tech Stack  
- **HTML5** – Structure  
- **CSS3** – Styling, animations, and theme switching  
- **JavaScript (ES6+)** – Stopwatch logic, lap tracking, and interactivity  

## 📖 Usage  

1. **Start** – Click **Start** to begin timing  
2. **Lap** – Record lap times without stopping  
3. **Pause/Resume** – Pause and continue seamlessly  
4. **Reset** – Clear laps and reset timer  
5. **Theme Toggle** – Switch between **Dark** 🌑 and **Light** ☀️ modes
